Black Ledger Arena Build Brief Package

Contains one Word document per arena. Each document includes the generated environment rendering, arena description, recommended playable footprint for 14 vehicles, Unreal scale notes, hazard/special-effect notes, destructible interactions, and graybox priorities.

Recommended size values are first-pass graybox targets and should be tuned after vehicle handling, average speed, weapon lock ranges, and boss hazard timing are implemented.
