# Placeholder & Reference Asset Shopping List

For fast prototyping (greybox → vertical slice). Prefer permissive licenses (CC0, Epic/Fab-licensed, CC-BY with attribution). Verify each license before shipping — placeholders get replaced before launch.

## Vehicles (placeholder)
- **Fab / Quixel (Epic)** — drivable car/truck base meshes, Epic-licensed for UE.
- **Sketchfab** — CC0/CC-BY ambulances, fire trucks, vans (filter by license).
- **Kenney "Car Kit" (CC0)** — blocky vehicles, ideal for greybox.
- Slice need: one boxy truck (Surgeon's ambulance stand-in) + 2–3 varied silhouettes for AI.

## Environment / props (the Mill first)
- **Fab / Megascans** — industrial metal, rust, concrete, debris (Epic-licensed).
- **Kenney / Sketchfab** — catwalks, pipes, barrels, containers, girders.
- Destructibles: author the break geometry in-engine (Chaos); grab modular industrial kits to dress the Mill.

## Audio — SFX
- **Freesound.org** (CC0/CC-BY) — engine loops, metal impacts, fire, alarms, debris.
- **Sonniss "GameAudioGDC"** free bundles — large royalty-free pro libraries.
- Build the 3-layer impacts (`AUDIO_EVENTS.md`) from these.

## Audio — music (temp)
- Royalty-free dark-ambient/industrial temp tracks (itch packs, Incompetech CC-BY) — temp only; commission original for launch.

## VO (scratch)
- Record scratch lines yourself or use TTS to time the barks/cinematics during the slice; cast real VO later (`AUDIO_DESIGN_BRIEF.md` §5).

## UI / fonts / icons
- **Kenney UI packs** (CC0) — buttons, HUD bits.
- **Google Fonts** — a heavy industrial display face + a clean body face.
- **game-icons.net** (CC-BY) — weapon/pickup icons.

## Reference only (mood, not for shipping)
- PureRef boards from stills of *Twisted Metal: Black*, *Silent Hill*, *Se7en*.

## Rule
Track every asset's source + license in `CREDITS/ASSET_LICENSES.md` from day one. Replace all placeholders before any public build.
